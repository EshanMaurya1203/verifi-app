# Verifii Design Philosophy & Core Principles

This document defines the foundational design principles that govern the Verifii Brand Design System. Every user touchpoint — including transactional emails, public landing pages, founder dashboards, Open Graph social images, PDFs, and future mobile push notifications — must adhere to these guidelines.

---

## 1. Trust Before Decoration

Verifii is the world's first verified revenue platform for Indian founders. Verification demands total accuracy, clarity, and authority. Visual design should emphasize legitimacy and transparency over ornamental fluff. Clear numbers, verified badges, and tamper-proof verification scores build instant trust.

## 2. Consistency Over Creativity

The brand experience must feel seamless regardless of channel. The website, transactional emails, and social previews share the exact same design tokens:
- Primary Brand Color: Lime-Green (`#b9ff4b`)
- Base Background: Pure Dark (`#080808`)
- Surface Background: Dark Surface (`#0f0f0f`)
- Typography: Headings in `Syne`, body text in `DM Sans` / system sans-serif.

Never create bespoke or ad-hoc color schemes for individual pages or templates.

## 3. Accessibility First

- **Contrast**: All interactive buttons use high-contrast dark text (`#080808`) on brand green (`#b9ff4b`), meeting WCAG AA contrast standards.
- **Readability**: Body copy must maintain high contrast against dark surfaces (`#f3f3f5` primary text, `#a1a1aa` secondary text).
- **Semantics**: Use proper HTML5 elements (`<h1>`–`<h3>`, `<p>`, `<a>`) with explicit `alt` text for images and logos.

## 4. Minimalism

- Eliminate visual noise.
- Every element must serve a functional purpose.
- Use whitespace, subtle borders (`rgba(255,255,255,0.08)` / `#262626`), and precise typography to establish layout hierarchy.

## 5. Professional SaaS Appearance

- Modern, sleek tech aesthetic tailored for ambitious founders, investors, and accelerators.
- Clean rounded corners (`8px` buttons, `12px` cards).
- Structured information architecture using cards, metrics, and badges.

## 6. Dark-First Design Language

- Dark-mode primary experience by default (`#080808` background with `#0f0f0f` surfaces).
- Vibrant brand green (`#b9ff4b`) accents draw focus directly to key calls-to-action and verification statuses.
